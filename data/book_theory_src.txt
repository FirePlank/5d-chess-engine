# Opening book source: annotated 5dpgn lines. `ktools bookgen data/book_theory_src.txt >
# data/book_theory.txt` turns it into the book the engine loads (a test checks the two agree).
#
# One game per non-comment line (a 5dpgn header and movetext). Each action may carry a tag in
# a comment right after it:
#   {play N}  the engine may play it, chosen at random with weight N among the position's
#             play moves (10: the guide's recommendation, 5: a good alternative, 2-3: a
#             playable sideline);
#   {know}    known theory the engine must not play itself (a blunder, a move the guide calls
#             dubious or not recommended, or the losing side's moves in a trap), kept so the
#             positions after it, and our reply there, are in the book.
# An untagged action takes the tag given to the same action from the same position elsewhere
# in the file (every action must be tagged somewhere; conflicting tags are an error).
#
# Sources (docs/theory/): t0_opening_guide.txt (Theory Gang, "T0 Openings Guide" v2.0, with its
# line numbers below), t0_common_openings.txt, f7_sac_guide_notes.md (Lavamat's f7-sac guide).
# Fixes to the guide's lines are noted where made: a missing " / " between White's and Black's
# move, "(>1L)" for "(>L1)", and moves that contradict the guide's own prose.
